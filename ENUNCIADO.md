# Material de partida — Fragment declarado en XML

Ejemplo docente de 2019 sobre **Fragments** en Android.

El objetivo es declarar un `Fragment` directamente desde el layout XML de la Activity y observar su integración y ciclo de vida. La reconstrucción añade una interacción mínima verificable: introducir un mensaje, pulsar **Procesar** y mostrar desde el Fragment el número de caracteres introducidos.

La versión moderna utiliza AndroidX y `FragmentContainerView`, manteniendo la técnica conceptual del ejemplo original.

No existe una base de datos asociada.
